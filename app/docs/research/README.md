# research

What each game rests on, and the study that tests it. Every file names its sources.

| Path | What it covers |
| --- | --- |
| [`healthy_baseline_study.txt`](healthy_baseline_study.txt) | The study design: every pre-registered check, the timings and the exclusions |
| [`design_check.md`](design_check.md) | Whether the collection gives the thesis every result: sample size, the sensor gap, the options |
| [`trial_mode.md`](trial_mode.md) | The 15, 30, 45 and 60 minute sittings: what each plays and why |
| [`new_modes/`](new_modes) | The literature per game and per condition, with the status of what was built |
| [`eeg/`](eeg) | EEG: the marker specification, the ERPs worth measuring, preparation, the trigger hardware |
| [`force_units.txt`](force_units.txt) | Force units and the pads' rating |
| [`rayan/`](rayan) | Rayan's sensor bench work and his scripts |

The largest files in `new_modes/` are [SRT sequence learning](new_modes/srt-sequence-learning.md) (the Reaction
card), [Force Pilot and Parkinson's](new_modes/force-pilot-parkinsons.md) and
[Syllables across ages](new_modes/syllables-all-ages.md); [`ranked.md`](new_modes/ranked.md) ranks the ideas for
further games.
