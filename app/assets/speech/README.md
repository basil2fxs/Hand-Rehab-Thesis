Spoken words and syllables for the Syllables mode. `chunks/<chunk>.wav` is one written chunk, recorded once as a spelling pronunciation and played in every word that holds it; `<word>.wav` (or `.ogg`) is the whole word; `<word>_<k>.ogg` is an older per-word render of the k-th syllable, used only where no chunk recording exists. `manifest.json` records who or what made the files, the date and each file's length and level.
Ships empty. A missing file falls back to the macOS `say` command on a developer Mac and to silence anywhere else, logged once per item.
Fill it by recording one Australian English voice: `python3 scripts/syllables_recording_kit.py list --pools adult,pseudo` writes the reading script (about 380 items for the adult profile; drop `--pools` for all of it), `cut` turns the recorded pages into these files and `check` lists what is still missing. The kit's docstring covers the session. `scripts/render_syllables_speech.py` is the older synthetic path; its `--provider say` output is for local testing only, never for git or the build.
