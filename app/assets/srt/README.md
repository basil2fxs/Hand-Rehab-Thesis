The SRT's four lane tones, copied unchanged from the lab's PsychoPy script (archive/Webler EEG past program/sounds): V.wav, B.wav, N.wav and M.wav, one per square from left to right.
Measured pitches are about 660, 700, 790 and 890 Hz (E5, F5, G5, A5); each file lasts about 200 ms, 48 kHz 16-bit stereo, and each tone is audible for about 115 to 130 ms. N and M are about 10 to 12 dB quieter than V and B (RMS about -28.5, -28.5, -38.8 and -40.5 dBFS).
The SRT plays the file for the square that flashes, as the script did; srt.tone_dir and srt.tone_files in config/default.yaml point here.
