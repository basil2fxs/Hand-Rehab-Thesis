# Icons

`pan_tool.png` is the Google Material Icons open palm, 96x96, Apache 2.0 (full text in [LICENSE](LICENSE)).

It draws the hand buttons on the setup screen and the hand badges on the lane strip, tinted to the theme and flipped for the left hand.

`app_icon.icns` and `app_icon.ico` are the standalone app's own icon on macOS and Windows.
