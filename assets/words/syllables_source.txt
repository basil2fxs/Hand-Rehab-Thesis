# Syllables word bank, source form. One word per line:
#
#     <band> <word split by hyphens, stressed syllable in CAPITALS>
#
# Example:  A ba-NA-na   ->  banana, syllables (ba, na, na), stress 1, band A
#
# scripts/build_syllables_bank.py turns this file into
# assets/words/syllables_bank.json, which the game loads. The build
# script validates every line: the chunks must join back to the
# spelling, every chunk must hold a vowel letter (the Year 1 rule
# AC9E1LY12: a syllable must contain a vowel sound), exactly one chunk
# carries the stress, 2 to 4 syllables, lower case a to z only, no
# duplicates. Any four-syllable word is forced to band C.
#
# Bands: A everyday words a young child meets daily, B words a child
# knows but meets less often, C rarer words and every four-syllable
# word.
#
# Splits follow spoken Australian pronunciation in the Macquarie
# convention, cut at the spelling boundary nearest the spoken one
# (rab-bit, not ra-bbit; ti-ger with the open first syllable). English
# syllable division in print is a convention, not a fact: Kearns
# (2020, Reading Research Quarterly) found the two taught rules fit
# 70.6 and 30.5 percent of applicable words. So the game never asks a
# child to place a boundary. It asks them to pick the chunk that was
# spoken, which is why one split per word is enough, and why the
# spoken syllable and the printed chunk have to agree exactly.
#
# PROVENANCE. Every line was written by hand for this project against
# ordinary Australian English usage. No word list, dictionary or
# corpus file was copied: not the Oxford Wordlist (copyright Oxford
# University Press, consulted as a reference idea only), not the
# Macquarie Dictionary (its splitting convention is a rule, not data),
# not SUBTLEX, cmudict or Moby Hyphenator. See LICENCE.txt beside this
# file, which also records the route to a larger bank built from those
# open sources if one is ever wanted.
#
# ADDING WORDS. Add the line to the right section, then run
#     python3 scripts/build_syllables_bank.py
# and commit this file and the regenerated JSON together.
