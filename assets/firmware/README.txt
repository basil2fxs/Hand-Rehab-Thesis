Firmware images the app can flash
================================

Build products, not source. Everything here except this file is
gitignored and regenerated by:

    python3 builds/build_firmware.py

which needs PlatformIO (pip install platformio). CI builds them on
every push and the app build downloads them as the firmware-hex
artefact, so a released app always carries hexes from its own commit.

What lands here
---------------
  finger_rehab_nano.hex            the game firmware
                                   (arduino/firmware_on_device)
  singletact_address_change.hex    the I2C address tool
                                   (arduino/singletact_address_change)
  manifest.json                    sha256, size, flash bytes and board
                                   per file, plus the build time and
                                   the commit they came from

The app checks each hex against manifest.json before flashing it. A
half written flash leaves a board with no working firmware at all, so a
damaged file is refused rather than sent to avrdude.

Verify a staged folder without rebuilding:

    python3 builds/build_firmware.py --check-only
