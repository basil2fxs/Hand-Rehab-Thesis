# Music

Tracks the menu and Rhythm mode play (`.mp3 .wav .ogg .flac`). Steady tempo, mostly instrumental, under 5 MB each.

CC0 or CC-BY only, with the licence text saved beside the track as `<song>.LICENCE.txt`. Credits: [ATTRIBUTION.md](ATTRIBUTION.md).

Empty folder means Rhythm mode will not start. Drop a track in and press Rescan on its setup screen.
