# Installers

| Folder | File | To install |
| --- | --- | --- |
| [`Windows/`](Windows) | `FingerRehab-Setup-Windows.exe` | Run it. Per user, no administrator, auto-start on |
| [`macOS/`](macOS) | `FingerRehab-macOS.dmg` | Open it, drag Finger Rehab into Applications |

Neither is signed, so the first open needs one click through: Windows, More info, Run anyway; macOS, System Settings, Privacy & Security, Open Anyway.

They are not kept in git (about 250 MB each). Take both, and `FingerRehab-EEGLab.zip`, from the same [build-apps run](https://github.com/basil2fxs/Hand-Rehab-Thesis/actions/workflows/build-apps.yml), so the three are one build.
