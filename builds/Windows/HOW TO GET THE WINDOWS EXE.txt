Finger Rehab for Windows
========================

The app is one file: Finger Rehab.exe. Copy it to any Windows PC and
double-click. Nothing to install. First launch takes a few seconds
while it unpacks, and Windows shows a one-time SmartScreen prompt
(More info, then Run anyway).

Windows apps can only be built on Windows, so this folder starts
empty. Either:

1. On a Windows PC with Python 3.11 or 3.12: copy the project over
   and run builds/build_app.bat. It installs PyInstaller, builds, and
   puts the exe here.

2. From GitHub: Actions tab, open the latest build-apps run, download
   FingerRehab-Windows.zip, unzip the exe into this folder.
